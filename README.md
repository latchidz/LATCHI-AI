# Latchi AI · 2.0

مساعد ذكي جزائري بمحرّك **تبديل تلقائي بين موديلات NVIDIA NIM**.
كل شيء مدمج: المحرّك، المفاتيح، الموديلات، الذاكرة — الواجهة ما تشوف حتى إعداد.

> 🔒 **مستودع خاص** — الكود والمفاتيح ماشي للعموم.

---

## ⚡ واش كيدير

| القدرة | الموديل | ملاحظة |
|---|---|---|
| 💬 محادثة بالدارجة | سلسلة 11 موديل | تبديل أوتوماتيكي كي يطيح واحد |
| 👁️ فهم الصور | `nemotron-3.5-super-vl-120b` | كنوصّف ← كنحوّل ← كنجاوب |
| 🎨 توليد الصور | `flux.1-dev` | الدارجة ← برومبت إنجليزي ← صورة |
| 🌐 ترجمة | `riva-translate-4b` | احتياطي |
| 🧠 ذاكرة محادثات | محلّية (JSON) | تبقى من بعد ما تسدّ |

---

## 🚀 التشغيل

```bash
cd app
pip install -r requirements.txt
# حطّ المفتاح فـ app/.env
echo "NVAPI_KEYS=nvapi-xxxxx" > .env
python3 -m uvicorn main:app --host 0.0.0.0 --port 8000
```

افتح `http://localhost:8000`.

## 🧠 كيفاش يخدم التبديل التلقائي

```
سؤال المستخدم
     ↓
[المحرّك] يبني سلسلة مرتبة: الأسرع والأنجح أولاً
     ↓
موديل ① ──✅──→ يجاوب وكمّل
   │
   ❌ (404 / timeout / رد فارغ / 429)
   ↓
[صحة] عقوبة تدريجية: 90s → 180s → 360s → 900s
   ↓
موديل ② ──✅──→ يكمّل **نفس الرسائل بالضبط**
```

**المستخدم ما كيحسّش بوالو** — غير يشوف `⚡ بدّل تلقائياً`.
كل محادثة كتحفظ آخر 24 رسالة، والموديل الجديد كيقراهم كاملين ⇒ يكمل من نفس النقطة.

### الملفات

| ملف | وظيفة |
|---|---|
| `engine/registry.py` | كل الإعدادات: سلاسل الموديلات، الشخصية، معايير التشغيل |
| `engine/health.py` | صحة كل موديل + عقوبات + رجوع تلقائي |
| `engine/nim.py` | اتصال NVIDIA: بث، رؤية، توليد صور |
| `engine/router.py` | المحرّك: اختيار المسار + التبديل + خط الأنابيب |
| `main.py` | الخادم: API + بث SSE |
| `static/` | الواجهة (HTML/CSS/JS · بلا أي مكتبة خارجية) |

## 🔐 الأمان

- المفاتيح فـ`.env` — **ماشي فـGit** (`.gitignore`)
- الواجهة ما تستقبلش ولا تشوف حتى مفتاح — كل النداءات من السيرفر
- موديلات وأسماء خفية: الواجهة غير كتشوف اسم مختصر
- `noindex, nofollow` على الصفحة
